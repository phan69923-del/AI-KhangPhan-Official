# 🚀 AI KhangPhan

Một ứng dụng web Chatbot AI cá nhân được phát triển bởi **Khang Phan** (Phan Tăng Hoàng Khang), Trường THCS Nguyễn trãi,P.Long Khánh,TP. Đồng Nai.

*🌟 Tính năng chính
- 🤖 Tích hợp các mô hình ngôn ngữ ( AI ) lớn hiện đại.
- 🔐 Xác thực người dùng an toàn qua *Google OAuth*.
- 🗄️ Lưu trữ dữ liệu và session với *MongoDB Atlas*.
- ⚡ Giao diện hiện đại, tối ưu trải nghiệm người dùng.

*🛠️ Công nghệ sử dụng
- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MongoDB Atlas
- **Deployment:** Vercel & Render

  **Cam Kết bảo mật Tuyệt đối cho đoạn chat và tuân thủ quyền riêng tư cho bạn!**

  🌐 Website chính thức: **https://ai-khangphan.vercel.app**
